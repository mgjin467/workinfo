칼퇴 업무정보 v0.9 사용설명서
전체 모듈 조회는 서로 다른 API를 동시에 조회하고 완료된 항목부터 결과를 표시·저장합니다. 각 API의 페이지는 순차 조회하므로 데이터가 많거나 서버 응답이 느리면 해당 항목은 계속 조회 중일 수 있습니다. 일부 항목 실패 또는 취소 시 이미 완료된 항목의 결과는 유지됩니다. 취소 요청 후 진행 중인 통신이 종료될 때까지 기다립니다.
조회 결과 삭제
각 조회 화면의
선택 삭제
로 선택한 행을 지울 수 있습니다. Ctrl 또는 Shift를 누르고 클릭하면 여러 행을 선택합니다.
전체 삭제
는 결과 내 검색 필터와 관계없이 해당 항목에 저장된 모든 결과와 관련 상태 변경 이력, 마지막 조회 시각을 삭제합니다. 대시보드·통합 알림함에도 반영되고 재실행해도 삭제 상태가 유지됩니다. API 키와 검색 조건은 유지됩니다. 다시 조회하거나 자동조회가 실행되면 조건에 맞는 결과가 다시 나타날 수 있습니다. 조회 중에는 삭제 버튼을 사용할 수 없습니다.

설정 저장을 누릅니다. 인증값이 없는 모듈은 전체 조회에서 건너뜁니다.
모듈별 검색 조건을 입력한 뒤 지금 조회를 누릅니다.

3. 모듈별 사용법
나라장터
용역·물품·공사·외자를 선택하고 기간을 지정합니다. 쉼표로 나눈 검색어 중 하나라도 일치하면 포함합니다. 기관·지역 필터는 각각 추가 조건입니다. API 목록의 지역 값이 없으면 지역 필터에 매칭되지 않을 수 있으므로 원문에서 참가자격을 확인하세요. 금액은 추정가격과 배정예산을 분리하며 값이 없는 경우 빈칸입니다. 기초금액과 같은 의미가 아닙니다. 기간은 작은 구간으로 나누고 모든 페이지를 조회하므로 넓은 기간은 시간이 걸립니다.
거래처 상태
한 줄에
거래처명, 사업자등록번호
를 입력합니다. 번호만 입력해도 됩니다. 거래처명에 쉼표가 있다면 큰따옴표로 감싸세요. 이름은 사용자가 입력한 값이며 국세청에서 확인된 상호가 아닙니다.
양식 저장으로 CSV 헤더를 만들고, 거래처명 / 사업자등록번호 열에 데이터를 채운 뒤 Excel/CSV 불러오기를 누릅니다. 사업자번호 열은 텍스트로 지정하여 앞자리 0을 보존하세요. UTF-8과 CP949 CSV를 지원합니다. 잘못된 행은 번호와 함께 알려주며, 오류를 수정한 뒤 다시 불러옵니다. 불러오기는 현재 목록에 번호 기준으로 병합합니다.
계속사업·휴업·폐업과 과세유형, 폐업일 등을 확인할 수 있습니다. 최초 조회 이후 운영상태나 과세유형이 바뀌면 신규/변경 건수에 포함하고 읽지 않음으로 표시합니다. 해당 번호의 최신 상태와 변경 이력은 PC에 저장합니다.
지원사업
분야·해시태그로 후보를 모읍니다. 최대 건수는 화면에 지정한 수이며 전체 공고 수가 아닙니다. 상세정보의 대상·사업개요를 확인하고 원문에서 신청 자격과 마감 조건을 확인하세요.
법령 변경
법령명을 줄바꿈 또는 쉼표로 입력합니다. 관련 법령명, 개정구분, 공포일, 시행일을 표시합니다. 법령별 검색은 최대 100건이며 조문 비교 기능은 포함하지 않습니다.
기업공시
기업번호 입력란에는 DART의 8자리 고유번호를 입력합니다. 사업자등록번호(10자리) 및 주식 종목코드(6자리)와 다릅니다.

4. 표, 상세정보, Excel
열 제목 경계선을 드래그하면 열 너비가 바뀝니다. 경계선을 더블클릭하면 내용에 맞춰집니다.
표 아래 가로 스크롤로 오른쪽 열을 봅니다. 창을 좁히면 메뉴가 아이콘으로 축소됩니다. 창 모서리 또는 오른쪽 아래 손잡이로 창 크기를 조절합니다.
행 선택 시 아래 상세창에 주요 값과 API의 모든 원본 필드가 표시됩니다. 구분선을 드래그하면 표/상세창 높이가 바뀝니다.
더블클릭 또는 상세정보 버튼으로 큰 창을 열고, 원문 열기로 공식 페이지를 엽니다.
결과 내 검색은 이미 조회한 행을 필터링합니다. Excel/CSV 저장은 필터 후 보이는 행을 저장합니다.
Excel에는 주요 정보와 API 상세값 시트가 함께 들어갑니다. 사업자번호와 코드의 앞자리 0은 유지됩니다. 외부 문자열은 수식으로 실행되지 않게 저장합니다.
우클릭으로 셀 복사, 행 전체 복사, 상세정보, 원문 열기를 사용할 수 있습니다. Ctrl+C는 현재 셀을 복사합니다.
5. 자동조회와 데이터
자동조회는 프로그램이 실행 중일 때만 동작합니다. Telegram Bot Token과 Chat ID를 설정하면 최초 조회 이후 새 항목과 거래처 상태 변경을 알려줍니다. 프로그램의 데이터는 %LOCALAPPDATA%\CompanyWatch에 저장됩니다. 인증값은 현재 Windows 사용자 계정으로 암호화됩니다. EXE만 교체하면 기존 설정과 조회 이력이 유지됩니다. 다른 PC/Windows 계정에서는 API 키를 다시 입력해야 합니다.
각 모듈은 마지막 성공 조회 시각을 표시합니다. 재실행 시 최근 저장 항목을 최대 10,000건 복원하며, 통합 알림함은 최근 500건을 표시합니다. 새로 조회하면 해당 조건의 결과로 교체됩니다. 조회 중 취소하면 진행 중 통신이 끝난 후 중단하고 해당 조회의 미완료 결과는 저장하지 않습니다. 종료도 통신 종료 후 안전하게 처리합니다.
6. 오류 해결
현상
확인 방법
인증 오류
해당 서비스 활용신청, 승인 여부, 키 만료, 붙여넣기 오류를 확인한 뒤 연결 시험을 실행합니다.
조회 결과 0건
기간을 늘리거나 기관·지역·검색어를 줄입니다. 정상 0건과 조회 실패는 별도 표시됩니다.
호출 한도 초과
자동조회 간격을 늘리고 조회기간을 줄입니다. 필요하면 제공기관에 한도 증설을 신청합니다.
Excel 저장 실패
동일 파일을 Excel에서 닫고 쓰기 가능한 위치에 저장합니다.
업체명이 없음
국세청 상태조회는 업체명을 반환하지 않습니다. 거래처명 열을 포함해 불러오거나 직접 입력하세요.
취소/종료 대기
현재 네트워크 요청이 완료될 때까지 기다립니다. 요청 시간 제한은 25초입니다.
